我做好了一個純 Python 標準函式庫的 CLI 登入系統，不需要額外安裝套件。

**檔案**（位於目前的工作資料夾）
- `auth.py`：核心邏輯。密碼用 PBKDF2-HMAC-SHA256（60 萬次迭代、每組隨機鹽）雜湊，資料檔不含明文。帳號不分大小寫、須為 3–32 字元的英數或底線；密碼至少 8 字元。資料寫入採暫存檔加原子替換，避免寫到一半毀損。帳號不存在時也會做一次雜湊，降低從回應時間猜測帳號的風險。
- `cli.py`：互動選單，提供註冊、登入、變更密碼、登出。密碼輸入不回顯，並以 `getpass` 實作。資料檔預設為家目錄下的 `.login_cli_users.json`，可用 `--db` 或環境變數 `USER_DB` 改路徑。
- `test_auth.py`：15 項單元測試。

**執行方式**
```
python cli.py
python -m unittest test_auth
```

**驗證結果**
- 單元測試 15 項全部通過。
- 用模擬輸入跑完整流程（註冊 → 無效選項 → 登入 → 變更密碼 → 登出 → 舊密碼被拒 → 新密碼登入 → 離開），結果正確，資料檔中只有雜湊值。
- 直接用管線餵入 CLI 時會卡住，原因推測是 Windows 上 `getpass` 會改讀主控台而非 stdin。這只影響自動化輸入，實際在終端機中使用不受影響，但我沒有在真正的互動終端機中測試過。
