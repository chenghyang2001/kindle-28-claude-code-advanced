這個資料夾屬於練習／演練性質（路徑含 `practice`），依你的全域規則，動手寫 `.py` 前要先確認要用哪種模式。

**請選一個：**

1. **快速 demo 模式（建議）**：派一個 code-writer 一次寫完，只跑一次冒煙測試，不跑 QA 和 reviewer。適合看懂流程。
2. **完整模式**：依三 agent 鐵律，code-writer → code-qa → code-reviewer 依序執行，並先確認複雜度與測試案例數。

確定模式後，我會照下面的預設設計實作，除非你要改：

- **功能**：`register`（註冊）、`login`（登入）、`logout`（登出）、`whoami`（查看目前登入者）、`change-password`（改密碼）。
- **儲存**：一個 JSON 使用者檔（路徑由環境變數或 `Path.home()` 決定，不硬編碼）。
- **密碼**：`hashlib.pbkdf2_hmac` + 隨機 salt，只用標準庫，不裝套件。
- **登入狀態**：寫入 session 檔，設定到期時間（預設 30 分鐘）。
- **錯誤處理**：檔案編碼一律 UTF-8、JSON 損毀與 I/O 錯誤有明確訊息、密碼輸入使用 `getpass`。
- **測試**：`if __name__ == "__main__"` 內含冒煙測試，涵蓋註冊、登入成功、登入失敗、重複帳號。

另外，你要的是**純 CLI 指令版**，還是**互動式選單版**（啟動後反覆出現選單）？預設我會做指令版。
