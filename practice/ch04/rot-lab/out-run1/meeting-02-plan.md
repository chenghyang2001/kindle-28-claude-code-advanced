# 會議 02 待辦執行建議

來源：`notes/meeting-02.md`（2026/10/08）。本會議決定資料庫維持 PostgreSQL 16。

## 小陳：撰寫 migration 腳本

建議先確認現有資料表結構與 PostgreSQL 16 的相容性，再列出需要變更的項目，例如新增欄位、索引與約束。每一支 migration 都應同時提供升級與回滾步驟，並且只做單一目的的變更，方便出問題時定位。腳本請先在測試環境用備份資料跑過一次，記錄執行時間與鎖表情況，避免正式環境停機。完成後請附上執行說明，讓其他成員也能重現結果。

## 小王：補登入頁單元測試

建議先整理登入頁的核心行為，包括帳號密碼正確與錯誤、欄位空白、錯誤提示與導向流程，再逐一寫成測試案例。測試應獨立執行，不依賴真實網路或外部服務，必要時使用 mock 取代。測試應以登入頁目前的實際版本為準，發現與原需求不符的地方，請回報給負責人確認。完成後把測試納入持續整合流程，確保後續修改不會破壞既有功能。
